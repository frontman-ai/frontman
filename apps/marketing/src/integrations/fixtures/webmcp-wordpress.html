Install Frontman for WordPress.

In wp-admin, open Plugins → Add New Plugin, install and activate Frontman. Sign in with GitHub or Google, then connect your AI provider.

Install plugin

WordPress 6.0+ and PHP 7.4+. Administrator access, Frontman sign-in and service access required. AI-provider costs are separate.

Safety

Know what changes immediately.

Frontman for WordPress is production-ready. Writes persist to the connected WordPress installation. Published content on a live site can change immediately; preview is not a universal approval gate. Draft publication and staging promotion still use your normal process.

Only administrators can access it. Tool requests use WordPress nonces. Site option writes are restricted to allowlisted settings. Keep backups and use staging for higher-risk work. Recovery is selective: Elementor snapshots and applicable WordPress revisions help with some changes, but there is no universal undo.
