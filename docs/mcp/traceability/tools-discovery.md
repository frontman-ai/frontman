# MCP Tools And Discovery Traceability

This matrix records requirements for Frontman's initial MCP `2026-07-28` discovery and tools implementation. Rows explicitly marked as custom-Phoenix runtime evidence reflect the Phase 1 consumer cutover; Streamable HTTP and later-phase behavior remain planning targets. Clients recognize and validate the core `input_required` result type, advertise no input capabilities, and have no automatic retry machinery; servers do not emit `input_required` initially.
