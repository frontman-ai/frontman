# MCP Tools And Discovery Traceability

This matrix records the current MCP `2026-07-28` discovery/tools implementation across JavaScript and WordPress Streamable HTTP, the browser HTTP client, browser custom-Phoenix server, and Phoenix custom-transport client. Active clients normalize absent `resultType` to `complete`, recognize and validate core `input_required`, surface it without retrying, and advertise no input capabilities. Servers emit only complete results. Conditional absence evidence is indexed in `../capability-support.md`.
