# MCP Base Protocol And Versioning Traceability

This matrix covers the normative requirements relevant to Phase 0 from the MCP `2026-07-28` base protocol, JSON-RPC messages, statelessness, schema usage, metadata, versioning and compatibility, extension negotiation, message-pattern overview, and custom transport rules. The architecture page contains no uppercase BCP 14 `MUST`, `MUST NOT`, `REQUIRED`, `SHOULD`, or `SHOULD NOT` statements; its descriptive constraints are represented by the normative rows below.
