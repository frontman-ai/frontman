# MCP Patterns and Optional Features Traceability

This matrix targets MCP `2026-07-28`. "Base receiver" rows apply even when Frontman does not advertise the corresponding optional feature. "Not advertised initially" rows describe production machinery that Frontman deliberately does not expose or execute in the initial scope. Planned tests are traceability targets, not claims that tests currently exist.
