# MCP Patterns and Optional Features Traceability

This current-state matrix targets MCP `2026-07-28`. Base receiver rows apply even when Frontman does not advertise the corresponding optional feature. Conditional rows cite evidence for the applicable direction and owner: JavaScript HTTP server dispatch is constrained by `FrontmanCore__MCP__MethodRequest` and active endpoint tests; WordPress server dispatch is constrained by `Frontman_MCP` and `McpTest.php`; browser custom-Phoenix server dispatch is constrained by `FrontmanClient__MCP` and its focused tests; browser HTTP client requests are constrained by `FrontmanClient__MCP__Client` and its loopback-server tests; Phoenix client requests and responses are constrained by `FrontmanServer.MCPConnection`, `ModelContextProtocol`, and their ExUnit suites. Shape-only evidence is identified separately from production behavior.
